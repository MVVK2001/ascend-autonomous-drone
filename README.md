# ASCEND Autonomous Drone

## Overview

ROS2 Humble based autonomous drone framework for:

- DJI F450 platform
- Gazebo Harmonic simulation
- MAVROS integration
- Autonomous waypoint navigation
- Terrain-aware airspace corridor planning
- Digital twin integration
- Object detection and inspection missions

## Technologies

- ROS2 Humble
- Gazebo Harmonic
- MAVROS
- ArduPilot SITL
- PX4
- RViz2
- Python
- C++
